# prpr-runtime

The runtime of parsers generated by [prpr](https://crates.io/crates/prpr), a Packrat parser generator for Parsing Expression Grammars.

Modules generated from grammar files, by the `prpr` command of [prpr-cli](https://crates.io/crates/prpr-cli) or by [prpr-codegen](https://crates.io/crates/prpr-codegen) in a build script, depend on this crate unless the runtime is included in them.
`include_parser!` includes the modules that build scripts generate.
Grammars written with the `grammar!` macro use the `prpr` crate instead, which provides this runtime as `prpr::runtime`.

With the feature `proc-macro2`, `SourceText` lets a prpr parser parse the input of a proc-macro and report errors at the right tokens.

See [the prpr Book](https://tanakh.github.io/prpr/) for how to use prpr.
