# prpr-cli

The `prpr` command of [prpr](https://crates.io/crates/prpr), a Packrat parser generator for Parsing Expression Grammars.
It generates Rust modules from grammar files.

```sh
cargo install prpr-cli
prpr gen src/list.peg -o src/list.rs
prpr check src/list.peg
```

See [Grammar files and the prpr command](https://tanakh.github.io/prpr/codegen/cli.html) in the prpr Book.
